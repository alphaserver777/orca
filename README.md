# Orca на dev1-robots

Настройки и сценарии нашей установки Orca. Исходники внешнего проекта: https://github.com/stablyai/orca, лицензия MIT. Здесь они не копируются в Git.

## Размещение

- `/opt/orca` — этот репозиторий, сценарии запуска и описание службы.
- `/opt/orca/runtime/orca-1.4.274` — официальный выпуск Orca с соответствующими файлами веб-интерфейса.
- `/opt/orca/runtime/codex-0.172.0` — официальный пакет `@openai/codex`.
- `/home/node` — профиль отдельного пользователя `orca`, история, вход Codex и рабочие копии. Прежний путь сохранён для совместимости истории.
- `/workspace` — перенесённый учебный репозиторий. Прежние данные внутри закрытого каталога пробной установки сохранены отдельно.
- `professorit-orca-native.service` — служба Linux. Ей не нужен Docker.

Служба принимает соединения только на `127.0.0.1:3040`. На компьютере используется существующее защищённое соединение и адрес http://localhost:3040/. Подключение телефона настраивается отдельно.

Пользователь `orca` не входит в группу администраторов и группу Docker. По решению владельца команды работают без изоляции Codex и без ограничения каталогов со стороны службы; действуют обычные права пользователя Linux. Для изменения настроек создавайте рабочую копию через Orca; основная установка защищена от случайной записи. Применение новых настроек службы выполняет администратор по поручению пользователя.

## Перенос из пробной установки

Однократный сценарий `migrate-from-pilot.py` запускается администратором после проверки отсутствия работающих агентов. Он проверяет свободные целевые пути, копирует фиксированные версии, останавливает только пробную Orca, сохраняет закрытый архив профиля и учебного проекта и создаёт отдельную службу. Исходные пробные данные не удаляются. Повторный запуск при существующих целевых данных останавливается без их перезаписи.

Для Codex используются прежний вход ChatGPT и модель `gpt-6.1-sol`. Инструкции `orca-cli` и `orchestration` переносятся вместе с профилем. Данные входа, история, ключи и ссылки сопряжения никогда не помещаются в этот репозиторий.

В профиле Codex установлен `sandbox_mode = "danger-full-access"` по прямому решению владельца. Проверка на настоящем проекте и полный процесс согласований выполняются отдельными задачами.

## Возврат к пробной установке

Остановите `professorit-orca-native.service`, сохраните закрытую копию `/home/node` и `/workspace`, затем включите `professorit-orca-pilot.service`. Исходные пробные данные сохранены. Перед возвратом обновите только закрытый файл входа Codex в старом профиле из текущего и восстановите его владельца 1000 и права 0600: вход ChatGPT мог обновиться после переноса. Не запускайте обе среды с одним профилем одновременно.
