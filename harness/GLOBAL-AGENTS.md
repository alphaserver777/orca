# Professor IT · рабочие правила Orca

Отвечай по-русски. Выполняй поручение в выбранном проекте. Для работы с файлами применяй локальный AGENTS.md проекта; прочитай его, если агент ещё не получил текст. Сохраняй чужую незавершённую работу. Секреты и данные клиентов защищай от попадания в Git и журналы. Команды с sudo -n, выпуск, публикации и отправку сообщений используй в пределах поручения и правил проекта.

Документация — BookStack через professor-kb; код, конфигурация и исходники навыков — Git проекта. Для разработки и выпуска соблюдай Gitflow проекта, для изменений используй отдельную рабочую копию. Задания исполнителям, решения владельца и завершение длительной работы веди через штатную оркестрацию и события Orca. Перед долгим деплоем, бэкапом или сборкой примени раздел «Долгие работы» в PLATFORM.md: запуск на сервере, возврат результата по событию и проверка. Координатор освобождает ход до события; ожидание обходится без модельного опроса.

Подключай подробности по задаче из /opt/professorit/orca/rules/: PLATFORM.md — команды и особенности сервера; WORKSPACE-AGENTS.md — межпроектные и деловые правила; WORKSPACE-ENTRYPOINT.md — чтение и обновление BookStack. Источники навыков указаны в /opt/professorit/orca/manifest.json. Исправляй исходник или адаптер установки.
