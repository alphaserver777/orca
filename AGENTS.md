# Правила проекта

- Отвечать по-русски, кратко и однозначно.
- Здесь хранятся настройки и сценарии развёртывания Orca, а не исходники внешнего проекта.
- Не добавлять в Git ключи, пароли, данные входа, ссылки сопряжения, историю разговоров и рабочие проекты.
- Каталог runtime исключён из Git. Профиль Orca и Codex расположен в /home/node.
- Работать в отдельных рабочих копиях. Изменять основную установку и перезапускать службу только по заданию пользователя.
- Перед изменением развёртывания сохранять отметку версии и закрытую резервную копию профиля.
- Изменения одного механизма оформлять отдельным коммитом. Не отправлять изменения без задания пользователя.
